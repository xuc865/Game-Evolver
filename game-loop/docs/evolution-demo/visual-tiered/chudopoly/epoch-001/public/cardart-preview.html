Chudopoly — card art proof sheet

Every card is cream printed stock in both themes (ART-DIRECTION §0): the toggle below changes the table, not the objects on it. One face markup per card is degraded by container queries at ≤82 / ≤66 / ≤60 / ≤34px — nothing is re-rendered, which is what lets table/cardnode.js build a face once and only reparent it.

1 — The owner defect: rent vs wild, no text, 28px

A rent bleeds its colour to the trim and has no cream chassis. A wild property keeps the cream property chassis and contains its colour. So the wild rent and the wild property are told apart by chassis, not by colour — which is the confusion the owner hit. Rents are the first row, wilds the second.

2 — Ten sets at 38px

The set must be nameable with no text. 38px falls in the ≤60px tier — three marks: the set band, the glyph at 58% of the card, and the value coin. Below 34px it collapses further, to a flood of the set colour with the glyph knocked out in white (see tier 4).

3 — Every glyph as a 1-bit silhouette at 14×14

The ART §6 gate, taken literally: each glyph — the ten sets AND the eleven actions — rasterised on a real 14×14 canvas, thresholded to pure black and white, shown at 8×. If two of these squares can be confused, the glyphs are confusable in a 20px upgrade chip on an opponent's board. The 44px vector above each square is reference only; the pixels are the gate.
