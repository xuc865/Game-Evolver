# VibeGame integration

This directory is derived from [`tettethu/VibeGame`](https://github.com/tettethu/VibeGame)
at upstream commit `cab478b` (2026-09-10 checkout).

provider-neutral model routing, the Krea2 binary image provider, Game-Evolver
baseline handoff metadata, and evolution-oriented Dashboard surfaces.
